# First_Verilog
Testing out Vivado and Making testbench for the first time.
This project is my first hands-on exploration of Verilog HDL and digital design using an FPGA. The goal was to understand how hardware is described and implemented using Verilog, focusing on:

Shift registers
Basic binary operations
Input/output handling (switches, buttons, LEDs)
Clock-driven sequential logic

All Verilog Files are under sources
